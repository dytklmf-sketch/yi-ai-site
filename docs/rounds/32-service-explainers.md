# 第三十二轮：业务页详解章节（2026-10-05）

## 实际改动

- 三个业务页各加第四章（`src/components/yi-ai/ServiceExplainer.astro`，数据在 `src/data/service-explainers.ts`），
  顺序为 适用场景 → 合作流程 → 详解 → 相关指南，吸顶目录 3 项 → 4 项（站长此前已同意子导航扩到 4 项）；
  相关指南章节改为浅色底以保持深浅交替。
  - **WorkBuddy · 版本与积分**：产品是什么（据官方概述）、个人版与企业版对比表、五条与采购直接相关的官方规则
    （积分不结转、只升不降与自动续费、专享版 100 人起购、企业版到期停用、与 CodeBuddy 共享积分），注明核对日期
    与官方来源链接。不写价格。
  - **模型服务 · 接入与计费**：Python 接入示例（CCG API 公开地址，模型名为占位符）、企业用量洽谈前要对齐的口径表、
    月度成本估算器（`CostEstimator.astro`：用量默认取指南算例，单价留空由用户填写，本站不预填价格；无 JS 时显示公式）。
  - **基础设施 · 部署与分工**：三种部署形态与使用方责任表、合作前要确认的分工、沿用既有边界说明（部分资源自用、
    第三方模型不在自有设施、位置/设备/容量/认证/SLA 单独确认）。
  - 每章右栏：对应需求单下载与 2–4 篇深入指南。
- 「询价准备」卡片增加对应需求单下载；WorkBuddy 证书区显示「证书有效期至 2026-12-31」
  （`workbuddyCredential.validUntil`，到期时与证书区一并处理）。
