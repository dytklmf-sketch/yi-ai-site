# 第三十五轮：WorkBuddy 官方价格（2026-10-05）

## 站长要求

找到官方 WorkBuddy 定价，放到网站页面上。

## 来源（2026-10-05 用浏览器打开并读取表格）

- 个人版：https://www.codebuddy.cn/docs/workbuddy/Pricing
  体验版免费；标准版 99 元/月（连续包月 70、连续包年 672 元/年）；高级版 199 元/月（140、1,344 元/年）；
  旗舰版 999 元/月（700、6,720 元/年）；每月实得积分 500 / 4,000 / 9,000 / 50,000（后三档含限时加赠
  2,000 / 5,000 / 30,000）；加量包 50 元 / 1,000 积分、有效期 1 个月。
- 企业版：https://cloud.tencent.com/document/product/1831/134332 （页面最近更新 2026-09-16）
  旗舰版 198 元/人/月或 2,376 元/人/年、1 人起购、腾讯云共享 VPC；专享版 316 元/人/月或 3,792 元/人/年、
  100 人起购、腾讯云专享 VPC；两者每人每月 2,000 Credits、团队共享；私有化企业版售前咨询、无用量限制。
