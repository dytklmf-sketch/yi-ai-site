# 第四十四轮：企业版 vs 个人版的细节与动效（2026-10-05）

## 站长要求

方向对了，细节要打磨，视觉观感和特效动效要做好。

## 实际改动

- **视觉**：企业版卡头部主题色渐变底、标题旁「198 元/人/月起」官方起价标签、外圈柔光；VS 改为带白色光环的
  渐变圆章；两卡行内边距统一，行改为圆角条带。
- **交互**：鼠标移到任意一行，两张卡的同一行同时高亮（`:has([data-row])`）；企业版卡悬停上浮 4px、光晕加深。
- **动效（滚入时只播放一次）**：VS 圆章弹出；企业版卡上浮并轻微放大入场；八行依次滑入、对勾依次弹出；一道光
  从左到右扫过企业版卡。全部为有限次动画，结束后页面无运行中的动画；系统「减少动态效果」时全部静止，悬停也不位移
  （BRAND.md：禁止循环动效）。
