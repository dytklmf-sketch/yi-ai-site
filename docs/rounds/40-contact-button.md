# 第四十轮：常驻「联系我们」按钮、相关指南紧凑列表（2026-10-05）

依据：《易AI 官网整体优化规划》与站长回答（悬浮按钮用「联系我们」；首页底部联系面板保留；相关指南用方案 A）。

## 实际改动

- **常驻按钮**：除联系页外，每页右下角一个「联系我们」按钮（桌面为带文字的胶囊，手机为 56px 圆形），颜色跟随
  页面主题。用原生 `<details>` 实现：不开 JavaScript 也能展开，Esc 关闭并回到按钮，点页面其他位置关闭。面板内容：
  当前业务方向、微信号与复制、邮箱（带主题）、查看联系页。原手机底部整条「咨询合作」按钮栏删除。
- **底部联系卡片删除**：业务页、关于页、常见问题页、资源页不再有底部扁卡片；「让 AI 易懂、易用、易落地」回到
  页脚（首页保留完整联系面板，标语在面板里）。
- **相关指南**：业务页改为两列紧凑列表（标题 + 一行摘要 + 箭头），四篇约占原来三分之一高度。

## 测试

`test-build.mjs`：联系页以外都有常驻按钮、不再有底部卡片、业务页相关指南为紧凑列表、关于页 3 章；
`test-enhancements.mjs`：手机文章页按钮可见、可展开、显示业务方向、Esc 关闭、跳到联系页且业务方向已选、联系页无按钮。
