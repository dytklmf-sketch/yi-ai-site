# 第五十轮：模型卡重做、三块卡片加光效与动效（2026-10-06）

## 站长要求

合作方式与流程的卡片做一些优化，动效加光效，接入与计费同理；模型目录里的卡片不好看，想办法做好看。

## 实际改动

- 模型卡：
  - 每个系列一个字母色块（Claude A、GPT O、Gemini G、Grok x、DeepSeek D、通义千问 Q、GLM Z、Kimi K、MiniMax M、豆包「豆」、MiMo Mi，
    图片与视频用图标），颜色取各家近似色并压暗到白字可读；卡片右上角有一层很淡的同色晕染，能力标签圆点也用该色。
  - 去掉顶部紫色细条；系列名、厂商两行排在色块右侧，国际/国产/多模态标签在右上。
  - 删去面板导语，「完整列表与实时价格见模型广场」移到按钮下方。面板 1280×800 约 675px（可视 681px），1440×900 约 762px（可视 771px）。
- 光效（三块共用 `.glow-card`，`data-glow`）：鼠标所在位置有柔和光斑，附近边框跟着发亮；只在支持悬停的设备上出现。
  `interactions.ts` 新增十几行，按指针位置写 `--gx/--gy`。
- 动效（仅在未开启减少动态效果时）：卡片进入视口时依次上浮，每张卡扫过一次斜向高光；流程卡的步骤数字按顺序点亮、
  连线向下画出；悬停时卡片上浮、色块轻微放大旋转。全部只播放一次，不循环。
- 接入与计费：两张卡加顶部渐变条与阴影；接入地址框改为渐变底；POST 标签改为实心紫；路径行悬停高亮；
  计费卡补「单次调用费用 = 输入 tokens × 输入单价 + 输出 tokens × 输出单价 + 缓存 tokens × 缓存单价」。
- 合作方式与流程：每张卡加图标色块（钥匙、楼宇、握手），卡头改为图标 + 标题 + 适用对象；步骤数字悬停时点亮。
- 测试：`test-build.mjs` 的模型卡断言改为匹配 `mc-family glow-card … data-glow`。
