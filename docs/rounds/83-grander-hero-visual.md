# 第八十三轮：首页首屏右侧更宏大（2026-10-11）

## 站长要求

第八十二轮的右侧不够宏大壮观，请改；不要在服务器和本机做大规模测试，上线后站长自己看。

## 实际改动（布局不变）

- 更大：首页 `.chapters .hero-visual` 宽度由 `min(100%, 66vh)` 改为 `min(100% + clamp(2rem, 7vw, 9rem), 86vh)`，
  可伸进右侧页边；1920×1080 下插图由约 672×482 增到约 806×658，1440×900 下由 537×378 增到 638×520。
- 光台：`StackVisual` 带标签版画布加高到 860×680，层叠下方加透视椭圆光台（三圈：外圈虚线、中圈、内圈亮线）、
  底部径向光晕与四个方位光点。
- 光柱：贯穿三层的竖向径向光柱（在层叠之后）。
- 轨道环：增加一圈内环（r=286），外环四条对角高亮弧；轨道宽度 112% → 108%，以免超出屏幕。
- 新元素都是静态的，沿用一次性淡入；无循环动效。
