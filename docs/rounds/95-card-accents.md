# 第九十五轮：修咨询框顶条白缝；卡片装饰按类型区分（2026-10-13）

## 站长要求

首页最下方咨询框顶部彩色细条上方有一点白色空白，修复；所有卡片只有这一种装饰（顶部彩条），单调、视觉疲劳。

## 原因（白缝）

顶部彩条是背景渐变，`background-position` 默认相对内边距盒（padding-box），彩条从 1px 边框之下开始；
`.cta-band .contact-panel` 边框透明，露出底下的白色背景，形成一像素白缝。其他卡片同理（浅色背景下不明显）。

## 实际改动（`site.css`，不改结构）

| 卡片                         | 位置                | 新装饰                                         |
| ---------------------------- | ------------------- | ---------------------------------------------- |
| 咨询框 `.contact-panel`      | 首页底部、联系页    | 保留顶部彩条，改为 `border-box` 定位，白缝消失 |
| 适用场景 `.scenario-grid li` | 三个业务页          | 左缘与图标平齐的竖向短条 + 右下角淡光          |
| 合作流程 `.step-card`        | WorkBuddy、基础设施 | 底部居中短线，悬停时向两侧展开                 |
| 合作范围 `.scope-panel`      | 三个业务页          | 四角取景框式折角                               |
| 接入与计费 `.ma-card`        | 模型服务            | 左上角淡光 + 浅主题色描边                      |
| 合作方式 `.mw-way`           | 模型服务            | 顶部淡色渐变头部                               |
| 部署方式对比 `.io-option`    | 基础设施            | 彩条移到底部                                   |
| 选型参考 `.is-card`          | 基础设施            | 去掉彩条，只留右上角淡光                       |

所有颜色仍取各业务页主题变量（`--cobalt*`、`--accent-rgb`）。
