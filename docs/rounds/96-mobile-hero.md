# 第九十六轮：手机首页首屏收进一屏（2026-10-15）

## 站长要求

先推一次 GitHub，然后优化手机页的效果（对接文档待办第 5 条：手机首页首屏高于屏幕，三层插图被挤到第二屏）。

## 原因

手机上首屏沿用桌面的间距与字号：标题 40px、导语行高 1.8、按钮 54px 高、徽章与插图之间留白大，
390×844 下首屏 1054px，插图从 612px 才开始，几乎全在第二屏。英文版两个按钮上下排，首屏 1162px。

## 实际改动（`site.css` 的 `max-width: 767px` 段，不改结构、不改文案）

- 首屏上下内边距收紧；眉题下距 0.75rem；标题 36px；导语 15px、行高 1.7、上距 1rem。
- 按钮 48px 高、内边距收窄；英文按钮 14px 字，两个按钮并排（放不下时仍自动换行）。
- 授权徽章 13px、`text-wrap: balance`，换行更匀。
- 三层插图高度上限 `min(36svh, 19rem)`；外圈圆环改为跟插图高度走（`height: 104%`），
  在 360–430 宽各尺寸都不压到上方徽章（第 91 轮「文字不压图形」）。

| 尺寸    | 中文首屏   | 英文首屏   |
| ------- | ---------- | ---------- |
| 390×844 | 1054 → 833 | 1162 → 859 |
| 375×667 | 974 → 763  | 1041 → 789 |

390×844 下中文版插图完整在第一屏；英文版只差插图底部几个像素。iPhone SE（667 高）屏幕太矮，插图上半部在第一屏。
平板和桌面不受影响。

## 测试（轻量）

- 本机 `pnpm format`、`pnpm check`、`pnpm build`、`pnpm test` 通过。
- 本机截图 390×844、375×667 中英文首页；360/375/390/430 宽量过圆环与徽章间距（均不重叠）、无横向滚动。

## 遗留

- 手机首页总长约 7200px 仍待站长决定是否删减内容。
