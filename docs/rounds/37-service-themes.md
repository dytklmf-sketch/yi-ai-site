# 第三十七轮（试行）：业务页主题色、价格上移（2026-10-05）

## 站长要求

1. WorkBuddy 价格放到比较靠上的位置。
2. 试一下每个业务页用自己的主题色：WorkBuddy 绿、CCG API 紫、机房蓝，参考页首示例卡片的颜色。

## 实际改动

- WorkBuddy 页「企业版价格」移到页首之后、适用场景之前，吸顶目录顺序为 企业版价格 → 适用场景 → 合作流程 → 相关指南。
- 布局在三个业务页的 `<body>` 上加 `data-theme`，只在 `main` 内覆盖强调色变量（`--cobalt` 系列、`--pale`、
  新增的 `--accent-rgb`），顶栏、页脚、联系按钮保持品牌蓝。颜色取自页首示例卡片（`.sample-stage`）：
  WorkBuddy `#097a64`（示例卡片 `#0b8a72` 在白底对比度不足 4.5:1，略加深）、CCG API `#5b3fd6`、机房 `#0a76b5`。
- `site.css` 中 33 处写死的品牌蓝光晕 `rgb(36 91 219 / x)` 改为 `rgb(var(--accent-rgb) / x)`，默认值不变，
  所以其他页面外观不变。
- `test-browser.mjs`：业务页正文主按钮为该页主题色，其他页面仍断言品牌蓝。

## 说明

这是试行方案：如站长决定恢复统一品牌蓝，删除 `site.css` 末尾三段 `body[data-theme=…] main` 规则并改回测试即可。
