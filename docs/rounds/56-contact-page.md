# 第五十六轮：联系合作页优化（2026-10-06）

## 站长要求

优化联系合作界面。

## 实际改动

- 联系面板（联系页与首页共用 `ContactPanel.astro`）：
  - 颜色跟随所选业务方向：WorkBuddy 绿、模型服务紫、基础设施蓝（CSS `:has()`，无 JS 时同样生效；色值与业务页主题一致）。
    面板顶部渐变条、角落晕染与阴影随之变色，并带 `.glow-card` 指针光效。
  - 业务方向选项改为卡片：各业务的产品标识 + 名称 + 一行简介（「企业版采购与续费」「模型 API 与企业用量」
    「自建机房 · 私有化」），选中时右侧实心对勾。需要准备区改为主题色虚线框。
  - 微信与邮件两张卡用 subgrid 共用五行（标题、说明、号码框、按钮、底部一行），号码框与按钮严格对齐，按钮通栏；
    邮件卡底部补一句「邮件会预填所选业务和需要准备的信息」（与微信卡的复制提示位等高，复制前后卡片高度不变）。
- 联系页首屏：导语下加三枚事实标签「微信、邮件均可」「邮件按业务预填」「需求单可下载」。
- 右侧栏：三个业务链接改为独立小卡片，各用自己的主题色，悬停上浮；合作流程四步改为用竖线串起的时间线，悬停点亮。

## 测试

- `pnpm check`、`pnpm build`、`pnpm test` 通过；截图核对联系页三种业务方向（1440）、手机端与首页联系面板。
- 完整 `pnpm test:browser`：通过：320 项响应式页面检查、80 次 axe 扫描、59 个内链、交互与无 JS 路由；Chromium 与 WebKit 增强流程、
  动效录屏、减少动态效果与重排。前三次失败都在测试脚本：品牌色检查读到了随业务变色的面板按钮（改为排除联系面板，
  另加「面板随所选业务变色」检查）；新检查读色早于按钮颜色过渡结束（改为等待）；点击后鼠标停在下一页主按钮上被读成
  悬停色（检查后把指针移到左上角）。
