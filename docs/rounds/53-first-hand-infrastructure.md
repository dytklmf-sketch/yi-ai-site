# 第五十三轮：一手机房资源与基础设施页详解（2026-10-06）

## 站长要求

基础设施页做详细。站长说明：机房资源手里没有现成的具体资料；「我们有，但是我们是一手资源，不是自己投资的」。

## 实际改动

- 全站措辞：「自建机房 / 拥有机房 / self-built data center」改为「一手机房资源 / first-hand data-center resources」
  （直接对接机房方，没有中间转手）。涉及首页导语、主营业务标签、「为什么选择易AI」卡、关于页、页脚、联系页描述、
  基础设施页标题与导语、页首示例窗口、常见问题，以及指南《基础设施需求怎么写》《机房合作的责任划分》中英文。
- 常见问题「自建机房资源是否全部对外开放？」换成「机房资源怎么确认能不能用？」；页面边界说明改为
  「资源来自直接合作的机房方；具体配置、数量、地区与周期按实际资源确认」。
- 基础设施页新增两章（数据在 `src/data/infra-detail.ts`）：
  - 部署方式对比 `#options`（`InfraOptions.astro`）：公有云 GPU、一手机房资源（中间，标「易AI 提供」，加粗边框并上浮）、
    企业本地私有化，各列适合、起步、计费、数据四项；均为行业通用对比，不写设备、数量、地区、SLA。
  - 选型参考 `#sizing`（`InfraSizing.astro`）：7B–70B 的 BF16 / INT4 权重显存与低并发推理参考档位，口径与指南
    《私有化部署开源模型：显存怎么估》一致，注明「档位只表示显存量级，不代表现货型号」；手机端每行变成小卡。
- 页面顺序：页首 → 部署方式对比 → 选型参考 → 适用场景 → 合作流程 → 相关指南（目录 5 项）。
- 测试：`test-build.mjs` 断言三种部署方式（一项标为易AI 提供）、选型表与指南链接，全站不出现「自建机房 / 自有机房 /
  self-built data」；三个业务页目录均为 5 项；`test-enhancements.mjs` 同步。
