# 第八十四轮：首页首屏右侧改为三幕轮换动效（2026-10-11）

## 站长要求

第八十三轮的右侧不好看、缺少动效。在对照页（`ccg-cli.online/docs/yiai-hero-board.html`）里站长很喜欢「E 算力矩阵」，
提出给应用、模型、算力各做一个动效图案，轮换出现；文字不能遮挡背景。

## 实际改动

- 新组件 `src/components/yi-ai/HeroScenes.astro`，替换首页右侧的三层插图与轨道环（`StackVisual` 仍用于 404）：
  - 应用（WorkBuddy 绿）：透视地面上 3×3 应用卡片，依次轻浮起并亮边。
  - 模型（模型服务紫）：3-5-5-3 分层网络，连线上光脉冲流动，节点轻微脉动。
  - 算力（基础设施蓝）：对照页 E 的 9×9 光柱阵列，由中心向外波浪起伏。
  - 每幕 6 秒，18 秒一轮交叉淡入淡出；名称放在插图下方一行三格（应用层 / 模型层 / 算力层 + 简述），
    当前一格变色并有进度细线，文字不压在图上。
- 纯 CSS 实现，无脚本；系统开启「减少动态效果」时停在第一幕，第一格高亮。
- 注意：CSS 压缩会把不带名称的 `animation` 简写变成 `animation: none`，轮换节奏用分写属性。
- `site.css`：删除第八十二、八十三轮的轨道环样式；新增场景样式。`BRAND.md` 与 `AGENTS.md` 记下首页轮换动效是站长要求的例外；
  `test-enhancements.mjs` 原「插图动效不循环」断言改为检查三幕轮换。

## 测试（按站长要求只做轻量检查）

- 本机 `pnpm check`、`pnpm build`、`pnpm test` 通过；本机截图 1440×900 三幕各一张、390 宽一张，无横向溢出、无脚本错误；
  用动画时间采样确认 0–6s 应用、6–12s 模型、12–18s 算力。
- 未跑浏览器测试套件。
