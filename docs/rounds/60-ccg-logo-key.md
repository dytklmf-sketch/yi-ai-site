## 实际改动

- 概念：中转站的产品就是模型页那句「一个 Key 调用各家主力模型」。图标是一把钥匙——钥匙环是一圈平滑的
  环形渐变（青 → 蓝 → 紫 → 品红 → 粉 → 琥珀），代表各家模型；白色钥匙杆与两级阶梯齿代表那一个 API Key。
- 探索：钥匙、棱镜（多色光汇入、白光射出）、折叠彩带「C」三个方向，在 120 / 48 / 32 / 24 / 16px、黑白底上对比。
  棱镜在 24px 以下糊成一团且容易联想到唱片封面；彩带「C」立体感不足、像通用字母 App；钥匙含义最直接、
  小尺寸最好认，选定后精修：
  - 四段硬拼色环像饼图，改为 60 段插值拼出平滑环形渐变，段间重叠 1.6° 消除拼缝，色带接缝藏在钥匙杆下。
  - 圆头描边的齿像肉瘤，改为整体在水平坐标里画出的实心轮廓（杆 + 两级阶梯齿，内角 1.5 圆角）再旋转 45°。
  - 按钥匙轴线中点居中；环宽 12、杆宽 10.5，保证 16–24px 可读；环后加同色紫光，杆用白到淡紫的金属渐变；
    深色圆角方块 + 顶部高光 + 9% 白色内描边，黑色导航栏上轮廓清楚。
- 替换中转站 `/var/www/html/logo.svg` 与易AI `public/partners/ccg-api.svg`；最早的原图标备份仍是
  `/var/www/html/logo.svg.bak-before-redesign-20261007`。
