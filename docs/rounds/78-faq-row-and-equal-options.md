# 第七十八轮：首页常见问题一行三张，部署方式对比不再突出易AI（2026-10-07）

## 站长要求

1. 首页「常见问题」三张卡片分成了两行，改成一行。
2. 基础设施页「部署方式对比」里不要强调「易AI 提供」，也不要高亮。

## 实际改动

- `FaqChapter.astro`：首页（非 `full`）的区块加 `faq-home`。`site.css`：首页标题与「查看全部问题」「咨询合作」排在同一行，
  下面三张卡占满全宽、1024 宽起一行三张；更窄时一张一行（三列在平板上过挤）。都未展开时三张等高，展开一张只撑高它自己
  （`:not(:has(details[open]))`）。常见问题页（18 条、侧栏筛选）不变。
- `InfraOptions.astro` / `infra-detail.ts`：去掉「易AI 提供」徽标、`ours` 标记与只在中间卡出现的「咨询机房资源」链接；
  中间卡说明「易AI 自建机房，按工作负载匹配」改为「按工作负载匹配机房资源」（英文同步）。
- `site.css`：删除 `.io-ours`（粗顶条、蓝边、上浮）、`.io-badge` 等样式；三张卡统一用其他业务卡同款 3px 顶部渐变细条。
- 首页常见问题改为整块一起淡入（`faq-layout` 带 `data-reveal`，标题行与卡片不再各自淡入）：标题行只有约 57px 高，
  WebKit 录屏时快速滚动偶尔漏触发，标题一直不出现（完整测试「Every section reveals once read」抓到，4 次复现 2 次）。
  常见问题页仍按原样分别淡入。
- `test-build.mjs`：基础设施页断言改为没有 `io-ours` / `io-badge`。
- 重新生成中文字体子集并还原拉丁字体。

## 测试

- 截图 390 / 768 / 1024 / 1440 / 1920：首页 FAQ 1024 起一行，基础设施三张卡同样式；常见问题页不变。
- `pnpm check`、`pnpm build`、`pnpm test` 通过。
- 完整 `pnpm test:browser`：第一次 WebKit「Every section reveals once read」失败（见上，已修），修后通过：320 项响应式页面检查、
  80 次 axe 扫描、59 个内链、交互与无 JS 路由；Chromium 与 WebKit 增强流程、动效录屏、减少动态效果与重排。
