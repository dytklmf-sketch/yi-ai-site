# 第五十一轮：模型卡换厂商图标，去掉授权相关说明（2026-10-06）

## 站长要求

模型卡直接放各厂家的图标（很多中转站这样做）；页面上不需要具体说明我们是不是官方授权。

## 实际改动

- 厂商图标：取自 `@lobehub/icons-static-svg` 1.95.1（MIT，CCG 模型广场也在用这套），原样保存在 `public/models/`，
  不引用外部 CDN。10 家用图标：Claude、OpenAI、Gemini、Grok、DeepSeek、通义千问、智谱、Kimi（单色版，彩色版的 K 是白色，
  白底上看不见）、MiniMax、豆包。MiMo 在图标库里只有一行很小的文字标，继续用字母「Mi」；图片与视频卡用图标。
- 色块改为白底圆角方块，边框和阴影带各家颜色，图标不改色、不改比例；卡片角落同色晕染保留。
  `model-catalog.ts` 每个系列新增 `icon`，原 `mark` 字母保留作后备（撤图标只需删一行）。
- 去掉授权相关说法（只涉及模型服务，WorkBuddy 的授权证书照旧）：
  - 模型页「适用场景」下的边界说明删除（`boundary` 改为可选，没有就不显示）。
  - 常见问题「供应合作等于模型厂商直供吗？」换成「支持哪些接口格式？」，总数仍 18 条。
  - 指南《模型供应合作的准备材料》中英文删掉「不是模型厂商直供」的要点和「是否要求模型厂商直接供货？」一节，要点余 3 条。
- 测试：`test-build.mjs` 断言模型页有 10 个自托管厂商图标，且不出现「官方授权 / 厂商直供」等字样。

## 测试

- `pnpm check`、`pnpm build`、`pnpm test` 通过；面板 1280×800 约 679px（可视 681px），1440×900 约 767px（可视 771px）。
- 完整 `pnpm test:browser`：通过：320 项响应式页面检查、80 次 axe 扫描、59 个内链、交互与无 JS 路由；Chromium 与 WebKit 增强流程、
  动效录屏、减少动态效果与重排。

## 遗留

- 如有厂商对图标使用提出异议，删掉对应系列的 `icon` 即回到字母色块。
