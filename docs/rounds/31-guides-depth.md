# 第三十一轮：指南扩写与新增（2026-10-05）

## 站长要求

P2 内容「重点丰富和详实」，针对网站实际内容改动；每轮上传 Git。

## 实际改动

- **扩写 6 篇现有指南（中英）**：每篇 8 个章节，正文约为原来的 2.2 倍（中文正文约 1600–2100 字）。
  新增内容是可直接使用的表格、样例与清单：WorkBuddy 个人版与企业版对比、积分规则；一页纸需求样例与选题打分表；
  模型比价表各列说明与「按合格结果算成本」算例（示例价格，明确标注不是报价）；资源说明样例与对账方法；
  工作负载需求样例与部署形态对比；责任分工矩阵与到期退出清单。每篇新增「常见误区」。
- **新增 6 篇指南（中英成对）**：OpenAI 兼容接口迁移清单、Token 用量与月度成本、私有化部署显存估算、
  训练/微调/推理的资源差异、企业生成式 AI 数据与合规清单、WorkBuddy 续费与人数调整。指南总数 6 → 12，
  站点页面 28 → 40。
- **可下载需求单**：`public/templates/{zh,en}/` 下 WorkBuddy 采购需求单、模型用量需求单、工作负载需求表（TXT）
  与模型比价表（CSV），UTF-8 BOM + CRLF，便于 Windows 记事本与 Excel 直接打开。指南内用相对链接引用，随 base 路径。
- **字体拆分**：`prepare-brand.py` 把中文子集分成两份。`noto-sans-sc-site.woff2` 只含界面文案与指南标题、摘要
  （178 KB → 132 KB，首页更小）；只在指南正文出现的字进 `noto-sans-sc-guides.woff2`（110 KB），由生成的
  `src/styles/font-guides.css` 用 `unicode-range` 声明，浏览器只在页面用到这些字时下载。分享图仍用 site 子集
  （标题与摘要都在其中）。
- **样式**：指南代码块用站点深色块（关闭 Shiki 内联配色）、手机上自动折行；表格在 720px 以下固定列宽、单元格内
  换行，320px 无横向溢出（曾试过可聚焦滚动容器，但 Astro 7 默认 Markdown 处理器不支持 rehype 插件，为免新增依赖改为纯 CSS）。
- **测试**：`test-build.mjs` 的页面数、分享图数、sitemap 数按指南数量推算；文章日期改为格式断言；新增模板文件
  BOM 断言与 guides 字体断言。`package-preview.mjs`、浏览器测试中的数量文案同步改为按路由数计算。
