# 第五十二轮：业务页的适用场景与合作流程套用模型页卡片风格（2026-10-06）

## 站长要求

开始下一轮 UI 优化。审查全站后列出四项可选；站长选了「其他业务页套用模型页的卡片风格」。

## 实际改动

- 适用场景（三个业务页）：原来一整块四宫格改为四张独立卡片——顶部主题色渐变条、右上角主题色晕染、阴影；
  图标改为主题色渐变方块白色图标。合作范围面板加顶部渐变条。
- 合作流程（WorkBuddy、基础设施）：每一步改为卡片（`.step-card`），数字仍居中显示；连接线改为在两张卡片之间的
  空隙里、与数字同高（手机端为竖线）。
- 光效与动效沿用第五十轮的 `.glow-card` / `.card-sheen`：指针光斑与边框光、卡片依次上浮并扫过一次高光、
  流程数字依次点亮、连接线画出。仅在未开启减少动态效果时播放一次。
- 颜色全部取页面主题变量：WorkBuddy 绿、模型服务紫、基础设施蓝。

## 测试

- `pnpm check`、`pnpm build`、`pnpm test` 通过；截图核对三页 1440 与 390 宽度、悬停与动画中间帧。
- 完整 `pnpm test:browser`：通过：320 项响应式页面检查、80 次 axe 扫描、59 个内链、交互与无 JS 路由；Chromium 与 WebKit 增强流程、
  动效录屏、减少动态效果与重排。

## 遗留

- 审查中另外三项待站长决定：首页卡片统一风格与小问题（合作伙伴 7 个 logo 留一个空格、首页常见问题 3 条排两列空一格）、
  首页 / 关于页的模型服务卡文案更新、基础设施页做详细（需要真实机房信息）。
