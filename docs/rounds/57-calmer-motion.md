# 第五十七轮：三个业务页页首都带图标，动效减弱（2026-10-06）

## 站长要求

WorkBuddy 页首左侧有一个小图标，另两个没有，都改成有；现在的动效太花眼，减弱。

## 实际改动

- 页首小标题前的产品图标：模型服务用 CCG API 标识（`/partners/ccg-api.svg`），基础设施用机房标识
  （`/partners/datacenter.svg`），与 WorkBuddy 一样；`[slug].astro` 用 `heroMarks` 统一取。
- 动效减弱（第五十至五十六轮加的卡片效果）：
  - 删除入场扫光：所有 `.card-sheen` 标记、样式与 `card-sheen` 关键帧。
  - 流程数字由「放大闪亮」改为只淡入（0.5 秒），连接线照常画出。
  - 卡片入场位移 1.25rem 加缩放改为 0.5rem 纯淡入上移，时长 0.7 → 0.5 秒。
  - 悬停：卡片上浮 3px → 1px；色块 / 图标放大加旋转改为只放大 3%。
  - 指针光斑浓度 13% → 7%，边框光 75% → 40%。
  - 仍只在未开启减少动态效果时播放一次。
- 未改：首页首屏插图与 WorkBuddy「企业版 vs 个人版」的入场动效（站长此前确认过）；如也嫌花，可再减。

## 测试

- `pnpm check`、`pnpm build`、`pnpm test` 通过；截图核对三页页首与模型目录入场中间帧。
- 完整 `pnpm test:browser`：通过：320 项响应式页面检查、80 次 axe 扫描、59 个内链、交互与无 JS 路由；Chromium 与 WebKit 增强流程、
  动效录屏、减少动态效果与重排。
