# 第三十九轮：WorkBuddy 只讲企业版、证书移到价格下方、去掉示例用量（2026-10-05）

依据：`易AI 官网整体优化规划`（站长审阅版）与站长的回答。

## 实际改动

- **只讲企业版**：采购需求单（中英）删去「个人版还是企业版」，改为意向版本与部署方式；WorkBuddy 页场景
  「个人账号转企业版」、可洽谈项「企业版三档怎么选」；常见问题把两条个人版问题换成「旗舰版和专享版怎么选」
  「私有化企业版适合谁」，开票只写企业版；两篇 WorkBuddy 指南按企业版重写（不再有个人版规则），并采用新写法：
  章节标题直接写内容，不用「先给结论」等模板标题。
- **企业版比个人版多什么**（站长要求）：WorkBuddy 页新增一章，三栏对比（对比项 / 个人版 / 企业版），企业版
  一栏放大加粗、用页面主题绿；八行内容全部来自 WorkBuddy 官方定价页与腾讯云版本说明，企业版以旗舰版为准。
  吸顶目录变为 5 项。
- **资质证书**移到企业版价格卡正下方（缩略图 + 授权名称 + 查看证书），合作流程底部的证书块删除；首页授权
  徽章改为链接到 `#editions`。
- **不写示例用量**：模型服务询价准备删去「每月约 2000 万 token」示例，改为一句「用量和价格因业务而异，请单独
  咨询」（字段 `briefExample` 改名 `briefNote`，不再带「例如」）；WorkBuddy 示例卡人数改为占位、现有账号改为
  「部分成员在用个人账号」；基础设施示例卡周期改为「按项目确定」。指南里的算例按站长回答保留。
- 指南卡片「本文包含」改为按标题过滤模板章节，不再按位置截取（新写法的指南也能正确列出）。

## 测试

`test-build.mjs`：WorkBuddy 页 5 个章节、价格卡后紧跟证书再到对比章节、8 行对比、首页徽章指向 `#editions`、
三个业务页不出现示例用量；`test-enhancements.mjs`：WorkBuddy 吸顶目录 5 项。完整 test:browser。
