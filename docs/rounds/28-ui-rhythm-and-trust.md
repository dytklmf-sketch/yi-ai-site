## 实际改动

- **U1 节奏**：`site.css` 桌面章节规则只给首页 Hero（满屏）和带吸顶目录的服务页页首（满屏减目录条）定高，
  其余章节对称内边距 `clamp(3.5rem, 9vh, 6.5rem)`；锚点改用全站 `scroll-padding`。紧跟首屏的章节
  `scroll-margin-top: -1.5rem`，点「了解服务」后不再露出一条深色 Hero、顶栏立即转实色。
- **U2 资源页**：页首按内容高度；三个分类章节合并为一个网格 + 业务筛选（与 FAQ 共用 `serviceFilter`，
  无 JS 时显示全部）；指南卡去掉六张相同的「更新于」日期（日期只留在文章页）。
- **U3 授权徽章**：措辞集中到 `yi-ai.ts` 的 `workbuddyCredential`（服务页证书区与首页共用），首页按钮下方
  「腾讯云 WorkBuddy / CodeBuddy 官方授权合作伙伴」链接到 `workbuddy/#process`。
- **U4 证书区**：标签与「易AI × WorkBuddy」改为上下排列、左对齐文字栏；手机缩略图 10rem（原 18rem 时扫描件
  的白底看起来像空白框）。
- **U5 为什么选择易AI**：从复述三项业务改为四条可核实的差异点（官方授权、统一接口与计费、自建机房、一个团队对接），
  每条附依据链接（证书、模型服务、基础设施、联系）。仅用既有确认事实。
- **U6 合作伙伴**：一份 logo、桌面 4×2 / 手机 2 列静态网格，默认灰度、悬停显示原色，与上方卡片用分隔线隔开；
  删除 4 份复制、暂停按钮和滚动脚本（符合 BRAND.md 不循环）。
- **U7 降噪**：删除 `WHY EASY AI`、`03 SERVICES`、卡片英文小标签和描边大编号；Hero 内的英文装饰保留。
- **U8 示例窗口**：打字从约 2.8–3.4 秒压到约 1.2 秒内完成（起始 300ms，代码 3ms/字，表单 22ms/字）。
- **U9 手机**：差异点改为图标在左的紧凑列表；手机章节间距 3.5rem；首页精选指南隐藏摘要；合作伙伴格高 3.5rem。
- 字体子集按 BRAND.md 重新生成：补上线上早已缺失的「专、跟、海、鱼」与新增的「拢」；logo 输出逐字节未变。
