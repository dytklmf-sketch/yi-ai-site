# 第三十四轮：WorkBuddy 版本章节重做与联系面板预填（2026-10-05）

## 站长决定（第三十二轮上线后）

- 模型服务、基础设施页新加的详解章节（接入与计费、部署与分工、成本估算器）不需要，删除。
- WorkBuddy 页的「版本与积分」保留，但精简内容，并对标 WorkBuddy 官网做好 UI。

## 实际改动

- **删除**：`ServiceExplainer.astro`、`CostEstimator.astro`、`service-explainers.ts`；模型服务与基础设施页恢复
  3 个章节（相关指南恢复白底）。保留「询价准备」卡片里的需求单下载（属于原有卡片，不是新章节）。
- **WorkBuddy 版本与积分**（`WorkBuddyEditions.astro`，数据 `src/data/workbuddy-editions.ts`）：参照
  codebuddy.cn/work 的视觉语言——黑色大圆角面板、WorkBuddy 绿（`#2fd39a`）强调标题关键词、并排深色卡片。
  内容从「介绍 + 5 行对比表 + 5 条要点 + 侧栏」精简为：一句话介绍、个人版 / Enterprise 两张卡（适合谁 + 3 点）、
  三个规则标签（积分不结转、个人版只升不降、企业版到期即停用）、一行底栏（下载采购需求单、两篇指南、来源与核对日期）。
- 第三十三轮 FAQ 中「模型服务页有估算工具」的回答改为指向 Token 成本指南。
- **联系面板**（联系页与首页共用）：每个业务方向使用自己的邮件正文，逐行列出该业务的询价要素；「需要准备」后加该
  业务需求单下载。需求单清单移到 `serviceBriefs`（与询价卡片共用）。
