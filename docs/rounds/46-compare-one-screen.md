# 第四十六轮：企业版 vs 个人版压到一屏、更多官方字标（2026-10-05）

- 个人版与企业版对比凝练到一屏能看完，不要往下翻。

  底部说明约 600px，1280×800 约 550px，均在一屏内（经吸顶目录跳转后完整可见）。手机上约 820px。

  （`public/partners/workbuddy-wordmark-white.svg`）。页面其余 WorkBuddy 字样是标题或正文（如「WorkBuddy 代理采购」
  「WorkBuddy 企业版」、授权名称），属于文字而非标志，保持文字；首页业务卡与图标位只用图标。
