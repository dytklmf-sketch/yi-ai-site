# 第九十一轮：大圆环版右侧文字不再压背景（2026-10-11）

## 站长要求

以第八十三轮的大圆环为基础往下迭代；右边的字不要挡背景。

## 原因

- 轨道环以整幅插图（含下方光台）为圆心，比三层叠板的中心低；最上一行标签离圆心远，正落在圆环收窄处，
  1440 宽时「WorkBuddy 代理采购」最远角离圆心 345px，刻度从 294px 开始。
- 标签字号用 rem，本站大屏会放大根字号，标签比图长得快，大屏上越界更多。
- 环内另有虚线圈（r=336）和内圈（r=286）正穿过标签区。

## 实际改动

- 轨道环圆心移到三层叠板中层（画布 y=275，`top: calc(1.5rem + (100% - 3rem) * 0.4044)`），光台仍在环内。
- 三行标签向中层收拢三分之一（`labelY`），连线改为从叠板边缘斜向引出；标签离叠板的间距 44 → 30。
- 插图内标签字号改用画布单位（px）：名称 28、说明 17（英文 14），随图等比缩放；说明字重 500、提亮。
- 删去环内的虚线圈与内圈；保留外圈、刻度、四段高亮弧、方位节点与中轴短线。

## 测试（轻量）

- 本机 `pnpm check`、`pnpm build`、`pnpm test` 通过。
- 测量 1280 / 1440 / 1920 / 2560，中英文：所有标签最远角与圆心距离 / 刻度内半径 = 0.93–0.95（改前 1.09–1.20），无横向溢出。
