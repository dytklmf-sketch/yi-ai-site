## 先给结论

采购 WorkBuddy 前，先写清楚**谁使用、用来做什么、买哪一类版本、使用多久、谁负责后续事项**。拿同一份需求向合作方核对，比只问一个折扣更有用。易AI提供代理采购咨询，本文是询价准备清单，不是产品权益清单或正式报价。

## 先分清个人版与企业版

WorkBuddy 的官方资料把购买方式分成两条线，采购前先确认走哪一条，后面的问题才问得准。

| 对比项       | 个人版套餐                       | 企业版（WorkBuddy Enterprise）                       |
| ------------ | -------------------------------- | ---------------------------------------------------- |
| 官方说明位置 | WorkBuddy 文档「定价详情」       | 腾讯云文档「版本说明」                               |
| 版本名称     | 体验版、标准版、高级版、旗舰版   | 旗舰版、专享版、私有化企业版                         |
| 计费方式     | 按账号订阅，按月或连续包月、包年 | 按人数订阅（元/人/月或元/人/年）；私有化企业版需咨询 |
| 用量单位     | 每月发放积分                     | 旗舰版、专享版按人赠送积分，团队内共享               |
| 管理能力     | 个人账号自行管理                 | 管理后台：授权管理、单点登录、成员统计等             |
| 部署位置     | 官方云端服务                     | 共享 VPC、独享 VPC 或企业本地部署                    |

以上按官方页面整理，核对日期为 2026-10-05，腾讯云版本说明页标注的更新时间为 2026-09-16。版本名称、价格和起购人数可能调整，下单前以官方页面和正式报价为准。

两点容易混淆：个人版里的「旗舰版」与企业版里的「旗舰版」是不同的东西；企业版的「专享版」官方说明为 100 人起购。

## 适用条件

适合首次为团队采购、为既有账号补充采购，以及准备比较不同采购方案的负责人。个人试用经验不能直接代表团队授权范围；已有账号也应说明归属和当前使用情况。

如果尚未选定产品，先列出两三个真实工作任务，再判断产品与需求是否相符。不要先假定某种部署、管理或集成功能存在。

## 一份可带走的采购清单

1. **使用对象**：团队角色、预计人数、先行验证的小组和最终使用者是否相同。
2. **实际任务**：输入什么材料，希望得到什么结果，哪些步骤仍由人审核。
3. **产品与授权**：准确版本名称、使用期限、账号归属、授权数量和允许的使用范围。
4. **现有环境**：操作系统、网络限制、已有账号以及涉及敏感资料的内部审批要求。
5. **费用口径**：报价对应的数量和期限，是否含税，续费条件及可能的额外费用。
6. **交付与责任**：开始时间、交付凭据、异常联系窗口，以及采购之外的服务由谁承担。

把每项标成「已确认 / 待确认 / 不需要」，保留确认日期与依据。未明确的事项应继续询问，不能用销售介绍中的模糊措辞替代。

可以直接下载[采购需求单](../../../templates/zh/workbuddy-purchase-brief.txt)填写，发邮件时作为附件。

## 积分怎么估

WorkBuddy 的对话请求都会消耗积分。官方说明里，消耗量取决于两点：所用模型的等级，以及任务的复杂度。长文档分析、多轮对话和知识库检索消耗更多，简短问答消耗更少。

几条与采购直接相关的规则（据官方「积分说明」）：

- 个人版积分按月发放，当月有效，**不结转**到下个月。
- 扣减时优先使用最先到期的积分；到期日相同时，先扣基础积分，再扣赠送积分。
- 积分用完可以购买加量包，加量包也有有效期。

这意味着「买大一档一定更划算」并不成立。建议先让三到五名典型用户用一到两周，记录每人每周的积分消耗，再决定版本。把这组数据交给合作方，报价会比按人数粗估更接近实际。

## 如何推进

1. **提交需求**：团队规模、任务描述、开通时间和现有账号情况。
2. **核对条件**：版本、数量、期限与报价条件；企业版还要确认部署方式和管理员人选。
3. **试用验证**：需要试用时，先确认是否可提供、额度及费用，不默认免费。
4. **确认订单**：逐项核对订单内容、发票信息与交付方式。
5. **开通交接**：确认账号分配、管理员、到期日和续费提醒由谁负责。

部署、培训、技术支持与售后应单独列项。采购咨询并不意味着这些服务已经包含，也不代表易AI承诺任何特定授权级别。

## 常见误区

- **把个人账号的体验当成团队方案**：个人版和企业版的管理能力、计费方式都不同，试用结论要按拟采购版本重新核对。
- **只比单价**：同一人数下，积分额度、管理后台和部署方式都会影响实际成本。
- **忽略到期和续费**：个人版连续包月、包年默认自动续费；企业授权到期后无法继续使用，需提前安排续费或调整人数。
- **默认含培训和售后**：产品订阅与实施服务是两件事，后者需要单独约定。

## 常见问题

### 能直接按照人数得到固定价格吗？

人数只是条件之一。版本、期限、订单安排及单独约定的服务都会影响方案。没有确认范围之前，不宜把估算当作最终报价。

### 产品介绍里的功能都包含吗？

应以拟采购版本的官方说明和实际确认结果核对。保存说明的版本与日期；遇到表述不一致时，先澄清再采购。

### 个人版能升级或退款吗？

官方「套餐管理」说明：个人版支持升级、不支持降级，升级时按剩余价值抵扣；退款有时间窗口和「未使用积分」等条件。具体以下单时的官方规则为准。

### 还没有完整需求能咨询吗？

可以。准备一个典型任务、人数范围与预计启动时间即可开始。不要在初次询问中发送密码、密钥或未经批准的业务原始资料。
